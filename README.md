# Tingly Learning Accelerator: Image Quality Assessment (IQA)
This Learning Accelerator for IQA is maintained by Tingly. Components include Knowledge Taxonomy; Process Taxonomy; Gap and Accelerator Analysis;  and links to previously published resources including articles, blogs and playground codes addressing a variety of IQA challenges.

### Key Highlights
- **Living Document**: This document is a version-controlled living document maintained on GitHub. New metrics (e.g., LIQE, MANIQA) or paradigms are updated as they emerge.
- **Contextualization**: This is not a "syllabus" but a "choose-your-own-adventure" map. Which means:
  - "If you're working on **denoising**, focus on Noise Modeling and the BRISQUE/PSNR metrics."
  - "If you're evaluating **AI-generated content**, dive into FID, LPIPS, and CLIP-IQA."
  - This prevents disorientation and channels directly to areas of interest for projects in hand.
- **From Toolkit to Platform**: Leverage the Jupyter Notebook toolkits and ready Python packages to standardize your IQA toolkit across projects.
