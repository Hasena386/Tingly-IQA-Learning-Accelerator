# Tingly Learning Accelerator: Image Quality Assessment (IQA)

A structured, practical guide to navigating the complex landscape of Image Quality Assessment. This accelerator provides a taxonomy of knowledge, a proven learning process, and actionable projects to efficiently go from foundational concepts to cutting edge semantic evaluation.

**➡️ Start your journey here:** **[IQA-Learning-Accelerator.md](IQA-Learning-Accelerator.md)**

---

## **Key Highlights**

### 🧠 **Strategic Learning Path**
This is not just a list of topics. It's a **strategic framework** that guides you through a logical progression:
*   **Pixel-based (PSNR)** → **Perception-based (SSIM)** → **Data-driven (BRISQUE/LPIPS)** → **Semantic (CLIP-IQA)**.

### 🗺️ **Choose-Your-Own-Adventure Map**
Avoid disorientation. The accelerator is designed for contextual learning based on your goals:
*   Working on **denoising**? Focus on **Noise Modeling, BRISQUE, and PSNR**.
*   Evaluating **AI-generated content**? Dive into **FID, LPIPS, and CLIP-IQA**.
*   This structure channels your effort directly into what matters for your project.

### 🛠️ **From Theory to Practice: Build Your Toolkit**
The guide provides blueprints for building your own quality assessment tools:
*   **FR-IQA Toolkit:** Compare two images with a dashboard of metrics (PSNR, SSIM, LPIPS...).
*   **NR-IQA Toolkit:** Analyze a single image with no-reference metrics (BRISQUE, NIQE, CLIP-IQA...).

### 🔄 **A Living Document**
The field of IQA evolves rapidly. This accelerator is **version-controlled** and updated on GitHub as new metrics (e.g., **LIQE, MANIQA**) and paradigms emerge.
